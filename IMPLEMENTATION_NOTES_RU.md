# Erosion — POSIX и Apps Management

## Что изменено

- POSIX mode/UID/GID для обычного файлового браузера читаются через `lstat(2)`. Для имён используется системная база iOS (`getpwuid` / `getgrgid`), затем `/etc/passwd` и `/etc/group`; добавлена резервная таблица базовых iPhone-пользователей и групп из `master.passwd.iPhone` и `group.iPhone`.
- Виртуальный список `/usr/libexec` использует UID/GID из `stat`, а не подставляет `root:wheel` каждой записи.
- Метаданные в `Apps → Bundles` отображают `root:wheel`, а Created/Modified — Unix epoch через локальный часовой пояс устройства.
- В Other добавлен раздел `May not work` → `Apps Management`.
- Apps Management получает установленные `.app` через InstallationProxy, иконки — через SpringBoard Services (`getIconPNGData`, тот же сервисный запрос, что использует StikDebug), а поиск — стандартным `.searchable`.
- Long-press контекстное меню содержит `Prepare`, `Decrypt`, `Export`. Два последних пункта заблокированы до успешного Prepare.
- Prepare использует существующий Airlift folder-reader и сохраняет распакованную `.app` в `Application Support/ErosionAppsManagement/Prepared/`. Манифест позволяет восстановить список подготовленных приложений после перезапуска Erosion.
- Export создаёт ZIP с директорией `.app`. Decrypt собирает `Payload/<App>.app`, архивирует Payload и переименовывает ZIP в `.ipa`.
- AFC POSIX mode сохраняется, когда устройство действительно возвращает `st_mode`. Если AFC mode не предоставляет, архиватор не назначает каждому файлу ошибочный `0600`, а сохраняет нормальные локальные права; после распаковки executable-файлы из `CFBundleExecutable` и embedded `.dylib` получают `0755`.

## Важные ограничения

- Название действия `Decrypt` соответствует запрошенному UI, но само действие **не снимает FairPlay-шифрование** с Mach-O. Оно только упаковывает уже подготовленную `.app` в структуру IPA.
- AFC не гарантирует предоставление исходного `st_mode`; поэтому точные исходные права нельзя восстановить, когда устройство их не передаёт. Исполняемые файлы восстанавливаются по bundle metadata, остальные файлы получают безопасные обычные режимы.
- Существующий Airlift folder export представляет обнаруженные симлинки как sidecar-файлы `.symlink.txt`; это ограничение старого транспортного формата осталось. Для приложений, которые критично зависят от внутренних симлинков, созданный IPA может потребовать дополнительной проверки.
- Иконки доступны, когда активны LocalDevVPN и pairing. Пока сервис недоступен, в списке отображается системная заглушка.
- Rust-библиотека AirliftFFI должна быть пересобрана на macOS. Workflow `Build Erosion IPA` выполняет этот шаг через `build-airlift-ffi.sh`; локальная Linux-среда здесь не содержит Cargo/Xcode, поэтому бинарный XCFramework в архиве не пересобран.
