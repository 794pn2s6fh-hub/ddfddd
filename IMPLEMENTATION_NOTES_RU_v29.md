# Erosion mod — v29

## Исправлено

### Other → Layouts
- Возвращена исходная рабочая реализация перестановки из v26: `ForEach(...).onMove`.
- Удалён экспериментальный drag-and-drop через `.draggable` / `.dropDestination`, который позволял перетаскивать полоску, но не обеспечивал корректное изменение порядка строк.
- `moveLayouts(from:to:)` сохраняет новый порядок в `layouts.json` и помечает новый первый layout для Apply.
- Контекстное меню Export / Rename / Delete сохранено.

### Custom Passcode → Explore / Library
- Сохранены текущие строки Explore и Library из v28, включая нативные `NavigationLink` и оформление списка.
- Убрано 12 pt верхнего отступа.
- Расстояние между блоками уменьшено с 18 до 10 pt.
- Высота контейнера Explore / Library увеличена с 104 до 112 pt, чтобы нижняя строка не обрезалась.
